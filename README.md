
# 📊 Microsoft Excel – Sales Data Analysis & Dashboard

Welcome to my **Microsoft Excel Portfolio Project!** 👋

This project was completed as part of the **Karirnex Microsoft Excel Bootcamp**, where I learned and applied various Excel functions and tools to process, analyze, and visualize sales transaction data.

Through four practical tasks, I explored how raw data can be transformed into meaningful insights to support business decision-making.

---

## 🎯 Project Overview

The main objective of this project is to develop practical skills in Microsoft Excel, particularly in data processing, data analysis, and visualization.

The project consists of four main tasks, starting from basic Excel calculations to building an interactive sales dashboard.

## 🛠️ Tools & Skills

- **Tool:** Microsoft Excel
- **Formulas & Functions:** SUM, AVERAGE, IF, COUNTIFS, SUMIFS, AVERAGEIFS, VLOOKUP, INDEX MATCH, and more.
- **Data Analysis:** Data Categorization, Filtering, and Conditional Analysis.
- **Data Summarization:** Pivot Table.
- **Data Visualization:** Charts and Pivot Charts.
- **Dashboard Development:** Slicer and Interactive Dashboard.

---

## 📌 Project Tasks

### 1️⃣ Task 1 – Basic Data Processing

Applied fundamental Excel formulas and functions to process transaction data and answer several business-related questions.

Key activities:
- Calculating average product quantity in Bandung.
- Identifying total sales from COD transactions.
- Identifying available sales platforms.
- Calculating total transactions in August 2025.
- Finding the best-selling egg brand in Surabaya through Toko Biru.

### 2️⃣ Task 2 – Data Categorization & Conditional Analysis

Created a new **Disc Category** variable based on Discount Amount to classify transactions into different discount levels.

Key activities:
- Calculating total quantity for the Clearance category.
- Summarizing Grand Total for the Rendah category.
- Analyzing average customer ratings by gender and discount category.
- Identifying the period with the highest quantity in the Tinggi category.
- Comparing transaction frequency and average Grand Total across discount categories.

### 3️⃣ Task 3 – Pivot Table Analysis

Utilized Pivot Tables to summarize large transaction datasets and analyze relationships across multiple business dimensions.

Key activities:
- Analyzing total Discount Amount by Payment Method.
- Comparing average Shipping Fee across cities.
- Summarizing Grand Total by Platform and Order Status.
- Analyzing Customer Rating by Gender and Discount Category.
- Identifying the Top 10 products based on total Grand Total.

### 4️⃣ Task 4 – Interactive Sales Dashboard

Developed an interactive Excel dashboard to visualize sales performance and provide business insights in a more accessible format.

Dashboard highlights:
- 📈 **Key Performance Indicators (KPIs):** Total Revenue, Total Quantity Sold, Total Orders, and Average Rating.
- 🛍️ **Top-Selling Products:** Identifying products with the highest sales quantity.
- 🌍 **Top 10 Cities:** Comparing sales performance across cities.
- 💸 **Discount Analysis:** Exploring differences in average Grand Total across discount categories.
- 🎛️ **Interactive Slicers:** Filtering dashboard results by Month and Year.
